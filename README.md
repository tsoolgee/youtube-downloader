# YT-DLP Studio

תוכנת שולחן עבודה להורדה מיוטיוב. ממשק HTML מלא בתוך חלון דסקטופ (pywebview) —
**בלי שרת מקומי, בלי פורטים, בלי דפדפן חיצוני**. המנוע הוא yt-dlp והמיזוג/המרה בעזרת FFmpeg.

## הורדה

**[⬇ להורדת הגרסה האחרונה](https://github.com/tsoolgee/youtube-downloader/releases/latest/download/YT-DLP-Studio.exe)**
— הקישור הזה קבוע ותמיד מצביע על הגרסה החדשה ביותר.
קובץ אחד, בלי התקנה, בלי פייתון ובלי FFmpeg.
הקובץ שנבנה נקרא **הורדה ניידת מיוטיוב צול גאה.exe**. בעמוד השחרור הוא מופיע
בתווית **יוטיוב הורדה**, אבל שם הקובץ עצמו שם הוא `YT-DLP-Studio.exe` — גיטהאב חותך
תווים לא-אנגליים משמות של קבצים מצורפים. אפשר לשנות את שם הקובץ אחרי ההורדה לכל שם,
זה לא משפיע על העדכונים.
התוכנה גם בודקת עדכונים בעצמה ומעדכנת את עצמה בלחיצה.

## הפעלה מהמקור
```
pip install -U yt-dlp pywebview
python app.py
```

## בניית EXE בודד
```
python build.py
```
התוצאה: `dist/YT-DLP Studio.exe` — קובץ אחד שרץ במחשב **בלי פייתון ובלי FFmpeg מותקן**.
FFmpeg ארוז דחוס בתוך ה-EXE ונפרס אוטומטית ל-`%LOCALAPPDATA%\YT-DLP Studio\bin`
בהפעלה הראשונה בלבד (בזמן הזה הצ'יפ בכותרת מציג "מכין FFmpeg…").

אפשרויות: `python build.py --ffmpeg "C:\path\to\ffmpeg\bin"` לצירוף בילד אחר,
`python build.py --no-ffmpeg` ל-EXE קטן שדורש FFmpeg במחשב היעד.
דרישה יחידה במחשב היעד: **WebView2 Runtime**, שמותקן כברירת מחדל בכל Windows 10/11 מעודכן.

## התרעה למשתמשים

הקובץ `notice.txt` שבשורש הריפו מוצג בתוך התוכנה כבאנר. עורכים אותו בגיטהאב,
והתוכנה מושכת אותו בכל פתיחה (וכל חצי שעה). תוכן `-` או קובץ ריק = בלי באנר.

טקסט חופשי — כל מה שכתוב בקובץ יוצג כמו שהוא:

```
תקלה ביוטיוב מאז אתמול, הורדות 4K עלולות להיכשל. עובדים על זה.
```

או JSON, לכותרת/צבע/קישור:

```json
{"title": "גרסה חדשה בדרך", "text": "ביום ראשון ייצא עדכון עם תמיכה בפלייליסטים פרטיים.",
 "level": "warn", "url": "https://tsoolgee.uk"}
```

`level` יכול להיות `info` (ברירת מחדל), `warn` או `error`. סגירת הבאנר על ידי המשתמש
נשמרת, ובאנר עם תוכן חדש יופיע שוב.

## יכולות
- הדבקת קישור בלחיצה אחת, וזיהוי אוטומטי של קישור חדש בלוח.
- **Enter מוסיף לתור** (Shift+Enter = שורה חדשה), גם כשהמיקוד לא בתיבה.
- קישורים מרובים — מופרדים ברווח, פסיק או שורה חדשה. גם גרירה של קישור לחלון.
- הוספת קישורים תוך כדי הורדה; תור עם הורדות מקבילות (עד 8).
- וידאו עד 4K ב-MP4 / MKV / WEBM, עם העדפת H.264+AAC ל-MP4 כדי שינגן בכל נגן.
- אודיו: MP3 / M4A / OPUS / FLAC / WAV עם בחירת קצב סיביות.
- **איכות נפרדת לכל הורדה** — כבוי כברירת מחדל; בהפעלה נפתח חלון כוונון לכל קישור.
  אותו קישור בשתי איכויות נשמר לשני קבצים נפרדים (`[720p] שם.mp4`).
- שני פסי התקדמות: ההורדה הנוכחית והתור כולו.
- כתוביות מוטמעות, תמונה ממוזערת, מטא-דאטה, דילוג על חסויות, פלייליסטים.
- הגבלת מהירות, עוגיות מדפדפן, תבנית שם קובץ, מצב כהה/בהיר.

הגדרות נשמרות ב-`%LOCALAPPDATA%\YT-DLP Studio\settings.json`.
